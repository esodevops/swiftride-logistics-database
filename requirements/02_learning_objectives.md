# Learning Objectives

Students will learn how to design, build, manage, and query a relational database using PostgreSQL.

## Database Design

Students will learn how to:

- Design relational databases.
- Understand data relationships.
- Create normalized database tables.
- Model one-to-one relationships.
- Model one-to-many relationships.
- Model many-to-many relationships.

## DDL: Data Definition Language

Students will learn how to create tables using DDL statements.

Key concepts include:

- Schemas
- Tables
- Columns
- Data types
- Primary keys
- Foreign keys
- Constraints

## DML: Data Manipulation Language

Students will learn how to:

- Insert records.
- Update records.
- Delete records.
- Manage changes to existing data.

## DQL: Data Query Language

Students will learn how to query data using SQL.

Key query concepts include:

- Filtering
- Sorting
- Aggregations
- Grouping
- Subqueries
- Joins

## Constraints and Validations

Students will implement:

- `PRIMARY KEY`
- `FOREIGN KEY`
- `UNIQUE`
- `CHECK`
- `NOT NULL`
- `DEFAULT`

## Cascading Rules

Students will use:

- `ON DELETE CASCADE`
- `ON UPDATE CASCADE`

These rules help manage related records automatically when parent records are deleted or updated.
