# Project Overview

## Project Title

SwiftRide Logistics Database Management System

## Specialization

Data Engineering

## Business Focus

SQL database design and query optimization.

## Primary Tool

PostgreSQL

## Project Purpose

This project exposes students to practical database engineering and relational database management using PostgreSQL.

SwiftRide Logistics needs a centralized database system that can automate operations, improve reporting, and keep business data consistent as the company grows.

## Target System

The proposed system is a PostgreSQL-powered relational database management system that:

- Centralizes operational data.
- Uses normalized relational tables.
- Enforces constraints and validations.
- Implements cascading operations.
- Supports efficient querying and reporting.
- Provides reliable relationships between entities.

## System Modules

- Customers
- Orders
- Drivers
- Deliveries
- Warehouses
- Inventory
- Payments
- Vehicles
